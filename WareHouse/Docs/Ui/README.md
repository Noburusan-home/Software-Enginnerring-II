# UI

Optional screen exports and mockups for warehouse features. **Screen Requirements** in each feature spec remain the source of truth for labels, routes, and empty/error copy.

Drop images or HTML exports here using a feature folder:

```text
Docs/Ui/
  README.md                 ← this file
  feature-1-orders/         ← supplier orders and shipments
  feature-2-damage/
  feature-3-equipment/
  feature-4-picking/
  feature-5-inventory/
  feature-6-low-stock/
  feature-7-returns/
  feature-8-receiving/
  feature-9-expiration/
  feature-10-locations/
```

Link frames from the matching feature’s **Screen Requirements** (in `Features Design (updated)/`). Images are guidance only.
